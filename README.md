# 聚变 JuBian AI · 变现聚合平台（演示站）

面向 AI 时代开发者的一站式变现聚合平台演示：聚合广告 / API 计费 / 订阅 / Agent 分成，含智能竞价、人群与意图、AI 物料审核、商单市场、微信风消息中心等控制台模块。

## 在线预览
GitHub Pages 部署后访问：`https://<用户名>.github.io/<仓库名>/`

- 落地页：`index.html`
- 登录/注册：`login.html`（点「一键进入」免注册体验）
- 控制台：`dashboard.html`

## 技术
纯静态站点（HTML + CSS + 原生 JS + Chart.js CDN），无需构建，直接打开或托管即可。
